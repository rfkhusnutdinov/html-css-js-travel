# Многостраничный сайт для клиента (фриланс-проект)

Многостраничный сайт, выполненный в рамках коммерческого заказа.
Проект демонстрирует адаптивную, кроссбраузерную вёрстку с использованием современных стандартов HTML, SCSS и сборки через Gulp + Rollup.

## 📦 Стек, сборка и особенности реализации

Проект базируется на моей сборке [Gulp сборке](https://github.com/rfkhusnutdinov/gulp-starter-kit):

- В текущей версии сборки используется **Pug** для разметки, но когда верстался проект использовался шаблонизатор **Nunjucks**
- **SCSS** для стилей
- **Rollup** для сборки JS
- **BrowserSync / live-reload** для удобной локальной разработки
- Минификация CSS/JS, оптимизация изображений, конвертация в WebP
- Организация стилей по компонентам (использую методологию БЭМ)
- Читабельный, структурированный и легко поддерживаемый код
